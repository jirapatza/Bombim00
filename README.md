# Bombim00 — Lottery Alert Dashboard

## Run locally

Use Node.js 22.14 or newer and Python 3.11 or newer.

```sh
npm ci
python3 -m pip install -r requirements.txt
cp .env.example .env
```

Set `DASH_PASSWORD` in `.env` before production use. Enter that same password in
the dashboard connection settings. Configure notification destinations separately.
Set `GITHUB_TOKEN` on the server/Worker to dispatch GitHub Actions without entering
a PAT in the browser. Browser-entered PATs are held in memory and cleared on reload.

```sh
npm run dev
# Production:
npm run build
npm start
```

`server.ts` is the server source. `server.js` and `dist/` are generated by the build
and are not committed. Rebuild after source changes before starting production.
Docker Compose requires `DASH_PASSWORD` in its environment or `.env` file.

## Check execution

Manual checks, local runner requests and the Node scheduler use one execution gate.
A concurrent request gets HTTP 409; a failed Python process gets HTTP 502 with its
diagnostics. `/api/trigger`, `/api/check-now` and `/api/simulate-runner` are compatible
URLs for that same implementation; the local runner executes real Python checks.

The Node scheduler runs every ten minutes unless `DISABLE_BACKGROUND_CHECK=true`.
If GitHub Actions is your automatic checker, set this flag to avoid scheduling the
same work independently on Node. Separate deployments do not share an execution
lock or notification history; use one automatic execution environment.

The Cloudflare Worker cannot execute Python. Its local runner URL returns HTTP 501.
Worker `/api/trigger` queues GitHub Actions and returns `queued: true`; this does not
mean that a check has completed. A configured Worker is the selected backend; the
dashboard does not fall back to another backend after a trigger failure.

Application creation, the workflow YAML editor, and arbitrary repository file
read/write APIs have been removed. Edit source and workflows through Git instead.
Unknown API routes return HTTP 404 with JSON.

## Verification

```sh
npm run lint
npm test
npm run test:runtime
python3 -m pytest -q
npm audit --audit-level=high
```

Runtime tests deliberately disable scheduled checks and prevent Python execution,
so they test failure handling without sending live notifications. Unit tests cover
the execution gate and retry behavior. Live provider availability, actual phone
delivery and browser layout require separate environment checks.

The Excel export dependency uses the official SheetJS 0.20.3 distribution at
<https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz>; the npm registry's old 0.18.5
release was replaced. `package-lock.json` pins resolved dependencies and integrity.
