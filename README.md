# Bombim00 — Lottery Alert Dashboard

## Architecture

- **Render** hosts the responsive web dashboard and API.
- **GitHub Actions** is the only lottery checker and notification runner. It runs on the scheduled workflow and on explicit manual dispatch.
- **GitHub repository JSON files** are the durable source of truth for settings, catalog, results, runtime status and self-healing audit history. Render's ephemeral filesystem is not used for application data.
- The dashboard sends manual checks to the single `lottery.yml` workflow. Render does not start a second Python runner or local scheduler.

## Run locally

Use Node.js 22.14 or newer and Python 3.11 or newer.

```sh
npm ci
python3 -m pip install -r requirements.txt
cp .env.example .env
```

Set `DASH_PASSWORD` and `GITHUB_TOKEN` in the server environment before using protected writes. Configure `LINE_CHANNEL_ACCESS_TOKEN`, `LINE_TARGET_ID`, and/or `NTFY_TOPIC` as GitHub Actions secrets for notifications. Never put secrets in `config/settings.json`, browser storage other than the short-lived dashboard session password, or committed files.

```sh
npm run dev
# Production:
npm run build
npm start
```

`server.ts` is the server source. `server.js` and `dist/` are generated by the build and are not committed.

## Verification

```sh
npm run lint
npm test
npm run test:runtime
python3 -m pytest -q
npm audit --audit-level=high
```

Runtime tests verify authentication, the GitHub Actions dispatch boundary, and removed legacy routes without triggering real checks or sending live notifications. Live provider availability, actual phone delivery and browser layout require separate environment checks.

The Excel export dependency uses the official SheetJS 0.20.3 distribution at
<https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz>; `package-lock.json` pins resolved dependencies and integrity.
