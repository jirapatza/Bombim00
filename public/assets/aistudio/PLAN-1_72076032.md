# Lottery Alert: แผนแยกระบบแจ้งเตือน + หน้าควบคุม (ไม่รวมสูตรหวย)

## โครงสร้างหลังจัดระเบียบ
```
lottery_checker.py  settings_loader.py  requirements.txt  lottery_previous_results.json
config/settings.json      <- ค่าตั้งที่หน้าเว็บแก้ได้ (ไม่มี ntfy topic)
status/status.json        <- workflow เขียน, หน้าเว็บอ่าน
dashboard/index.html      <- หน้าควบคุม (static)
api/worker.js             <- proxy ถือ GitHub token + รหัสผ่าน
tests/  .github/workflows/  docs/  archive/{android,web-template}
```

## ขั้นตอน
1. จัดโครงสร้าง: `scripts/restructure.sh` (ย้ายแอป Android และเทมเพลต React ไป archive/ ย้อนกลับได้ด้วย git) แล้วเลือก default branch เดียวใน GitHub Settings
2. คอนฟิก: คัดลอก `config/settings.json`, `settings_loader.py`, `tests/test_settings_loader.py` ไปไว้ใน repo
3. ต่อเข้ากับตัวเช็ก (แก้มือใน `lottery_checker.py` เพราะยังไม่ได้เห็นโค้ด):
   - ต้นโปรแกรม: `import settings_loader as sl; S = sl.load()`
   - ข้ามแหล่งที่ปิดไว้: `if not sl.source_enabled(S, "pholhuay"): ...` (ชื่อ key ดูใน settings.json)
   - ก่อนส่ง ntfy กรองด้วย `[r for r in rows if sl.should_notify(S, r)]` และใช้ `S["ntfy"]["server"]`
   - ท้ายโปรแกรม: `sl.write_status(rows)` (rows คือแถวผลลัพธ์ที่มีคีย์ภาษาไทยเดียวกับ lottery_previous_results.json)
4. workflow: รวม `docs/workflow-snippet.yml.txt` เข้า `lottery.yml` (commit status.json + ประวัติ)
5. Worker: deploy `api/worker.js` บน Cloudflare Workers ตั้ง secrets `GITHUB_TOKEN` (fine-grained เฉพาะ repo นี้: Actions + Contents อ่าน/เขียน) และ `DASH_PASSWORD` (ยาวและสุ่ม) ตั้ง vars `REPO`, `BRANCH`, `WORKFLOW`, `ALLOW_ORIGIN`
6. หน้าเว็บ: เปิด `dashboard/index.html` จากที่ไหนก็ได้ (GitHub Pages หรือเปิดในเครื่อง) ใส่ API URL, Raw base, รหัสผ่าน

## ทำก่อนเปิดใช้
- เปลี่ยน ntfy topic ใหม่ (repo เป็น public) เก็บเป็น secret `NTFY_TOPIC` และลบ topic เดิมออกจาก LOTTERY_SETUP.md
- ถ้าไม่ตั้ง Worker หน้าเว็บยังดูสถานะและค่าตั้งได้แบบอ่านอย่างเดียว
